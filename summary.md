This project implements a machine learning solution for house price prediction with an interest-rate scenario simulator.

The model was trained, evaluated, and tested successfully using a Ridge Regression pipeline on the Ames House Prices dataset (RMSE: $30,646.44, MAE: $19,040.57, R²: 0.8776).
All required outputs such as metrics, residual plots, and sample predictions are included.

The project demonstrates end-to-end ML pipeline implementation, from data preprocessing through model training, evaluation, and an interactive scenario simulation layer.
